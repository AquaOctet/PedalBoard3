# Pedalboard 3 1.0.0-beta.2

The second public beta. It's still a pre-release, so keep backups of the boards you care about.

Most of this release is about adding plugins where you meant to add them, and about the window getting out of the way. If you're coming from beta.1, the first item is the one you'll notice.

## What's new since beta.1

- **A plugin lands where you put it.** Dropping a plugin on the board used to place the card where you let go and then add it at the end of the chain anyway, so the picture and the signal disagreed and you had to rewire by hand. Now the position decides, on every path that has one: a drop on the canvas, a drop on a cable, and the Add Plugin menu opened at a point.
- **Dropping a plugin on a cable splices it into that cable.** The plugin goes between the two ends you dropped it on, wired up, in one gesture.
- **Closing the window keeps the board running.** The close button now hides the window and leaves the audio running, with an icon in the notification area -- the menu bar on macOS -- to bring it back. On a pedalboard, hitting the wrong corner mid-set shouldn't stop the sound. The first time it happens the app says so, and names the audio device it's still holding.
  - Quit from the tray icon, or from the menu, quits properly and still asks about unsaved changes.
  - If you'd rather the close button quit, turn off **Closing the window keeps it running** in Settings.
  - On a desktop that gives the app nowhere to put a tray icon, closing quits as it always did, whatever the setting says.
- **A new app icon,** drawn rather than scaled. Every size in the Windows icon is drawn for that size, including the ones 125%, 150% and 175% display scaling ask for, so it stays sharp in the taskbar and in Explorer instead of turning to mush at small sizes.
  - On Windows the title bar's corner now carries a single-colour version of it, which stays legible on a dark, light or accent-coloured title bar and follows the Windows theme while the app is open.
- **Less clutter in the window.** The plugin browser's filter is one control rather than a row of separate pills; the coloured stripe that every plugin row carried is gone, along with the format caption that repeated itself down each section; and the panel buttons now show which panel they fold away rather than three identical glyphs.

## Where things go

On Windows:

| What | Where |
|---|---|
| The app (installer) | `C:\Program Files\Pedalboard 3` |
| The app (portable zip) | Wherever you unzip it |
| Your boards | `Documents\Pedalboard 3\Patches`. Open and Save As start there. |
| Recordings | `Documents\Pedalboard 3\Recordings` |
| Settings and the plugin list | `%APPDATA%\Pedalboard 3` |

Uninstalling leaves your boards, recordings and settings where they are.

## Known limitations

- **Unsigned.** On first run, Windows SmartScreen says the app is from an unknown publisher (choose **More info**, then **Run anyway**). On macOS, right-click the app and choose **Open**.
- **No CLAP or VST2 hosting** in this beta.
- **Windows is the most tested platform.** macOS and Linux run the same automated tests on every change, but
  they get far less hands-on use, so expect rougher edges there.
- **On macOS, a plugin that crashes takes the app down with it.** On Windows and Linux a crashing plugin
  becomes a placeholder and the rest of the board keeps playing.
- **No plugin delay compensation.** A plugin that reports latency isn't compensated for, so two parallel
  paths through the board can drift apart by that much. A single chain is unaffected.
- **The main window's look is still changing** before 1.0.
- **On Linux the window has no icon of its own.** There's no desktop entry yet, so the window manager has
  nothing to read one from.
- **Windows file details show 1.0.0.** In a file's Properties, `Pedalboard 3.exe` shows version 1.0.0; the app and the installer show 1.0.0-beta.2.
