# Pedalboard 3 1.0.0-beta.1

This is the first public beta of Pedalboard 3, a rewrite of Pedalboard2 on JUCE 8. It's a pre-release, so keep backups of the boards you care about.

## What's in it

- **Plugins.** VST3 on Windows, macOS and Linux, plus Audio Units on macOS and LV2 on macOS and Linux.
  - Plugins are scanned in a separate process, so a plugin that crashes during the scan can't take the app down with it.
- **Boards.** A board is a bank of patches that works as a set list. A MIDI Program Change switches patches.
  - Pedalboard 3 opens Pedalboard2 `.pdl` files.
  - A patch whose plugins aren't installed still opens: the missing plugins become placeholders.
- **Mappings.** MIDI and OSC control of plugin parameters. App-wide mappings cover things like next and previous patch.
- **Transport and tools.** Tempo, a metronome, a looper, a file player and a recorder.
  - Tempo and the metronome can be switched off in Settings.
- **Editing.** Undo and redo, Open Recent, and opening a board by dropping it on the window. The window remembers its size and position.

## Where things go

On Windows:

| What | Where |
|---|---|
| The app (installer) | `C:\Program Files\Pedalboard 3` |
| The app (portable zip) | Wherever you unzip it |
| Your boards | `Documents\Pedalboard 3\Patches`. Open and Save As start there. |
| Recordings | `Documents\Pedalboard 3\Recordings` |
| Settings and the plugin list | `%APPDATA%\Pedalboard 3` |

Uninstalling leaves your boards, recordings and settings where they are.

## Known limitations

- **Unsigned.** On first run, Windows SmartScreen says the app is from an unknown publisher (choose **More info**, then **Run anyway**). On macOS, right-click the app and choose **Open**.
- **No CLAP or VST2 hosting** in this beta.
- **Windows is the most tested platform.** macOS and Linux run the same automated tests on every change, but
  they get far less hands-on use, so expect rougher edges there.
- **On macOS, a plugin that crashes takes the app down with it.** On Windows and Linux a crashing plugin
  becomes a placeholder and the rest of the board keeps playing.
- **No plugin delay compensation.** A plugin that reports latency isn't compensated for, so two parallel
  paths through the board can drift apart by that much. A single chain is unaffected.
- **The main window's look is still changing** before 1.0.
- **Windows file details show 1.0.0.** In a file's Properties, `Pedalboard 3.exe` shows version 1.0.0; the app and the installer show 1.0.0-beta.1.
